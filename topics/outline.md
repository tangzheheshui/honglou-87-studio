# 选题大纲总表(候选池)

题式两种基本骨架(系列前缀见各系列标题行):

- **人物式**:《红楼梦中的小人物——XX:副标题给冲突/命运》
- **主题式**:《红楼梦中的XX——副标题给一句话观点》

**八个系列,约 129 期候选**。除已立项的刘姥姥(01期)外均为候选;立项流程见 [README.md](README.md)。★ = 建议先做/涨粉期。

## 小人物系列固定讲稿结构(A系列通用,对接根README工作流第4步)

1. **钩子**:破除刻板印象——"大家以为他是XX,其实……"(=冷开场争议钩子)
2. **底牌**:出身、身份、手里有什么筹码(=人物弧线)
3. **关键事件**:87版对应片段讲他/她的选择(切片登记,引用片段id)
4. **矛盾点**:善与恶、清醒与局限、挣扎与妥协(=关键场景拆解)
5. **落点**:⚠️别每期都落在"规则困住了她"——统一十期观众就看穿公式,轮换落点:制度/人心/代价/幸存
6. **收尾**:87版演员演绎与改编处理(=主题升华+系列特色)
